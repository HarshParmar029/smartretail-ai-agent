\# SmartRetail AI Agent 🛒



AI-powered retail mall agent built with MongoDB Atlas + Flask.



\## Features

\- Find products across stores

\- Check store locations

\- Real-time inventory from MongoDB Atlas



\## Tech Stack

\- Python + Flask

\- MongoDB Atlas

\- Google Cloud



\## Run locally

```

pip install flask pymongo python-dotenv

python app.py

```
